# 初学者FDE学习之路

## 写在前面的话
FDE现在是一个特别火的名词, 随着AI在企业里更多的使用, FDE必然在接下来的时间段会更加紧缺. 

对于程序员或者产品经理来学, 转型FDE可能是当前最好的选择.

但是, 现在的问题是市面上的很多材料都特别虚, 都没有说在点子上.

本文从一个初学者开始说,如果开始FDE课程

## 面向谁
这篇文章面向对计算机编程有一定了解, 并且(最好)会使用Claude Code或者Codex的 朋友. 

简单来说, 最好能手搓, 其次是能vibe coding出来下面的小东西

1. Python 能写一小段代码，读文件, 会写循环, 会写if, break等等
2. SQL 会对表进行增删改查, 会join.
3. Git 能拉代码、能提交.

然后照着这里做, [SQLite 数据库指南：从零开始掌握 Python 数据库操作](https://blog.csdn.net/2301_80216352/article/details/155320108)。
会用python对sqlite 进行增删改查即可.

## 第一阶段
学习使用Python + FastAPI.
从市面上的工作需求来看, 对于Python的需求是最大的.
